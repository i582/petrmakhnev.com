Acton

Toolchain & development environment · TON Core

Led the design and development of Acton as part of a two-person team. The unified toolchain for TON smart contract development includes a language server, static analyzer, formatter, and debugger, alongside Acton Studio and Localton for running a private local network with a web UI.

Developers can build, test, debug, and deploy projects with Acton directly from VS Code and JetBrains IDEs.

Acton makes testing much simpler by letting developers write tests in the same language as their smart contracts, scripts simplify deployment, and local blockchain environments make dApp development easier.

Wallet Engine

Wallet infrastructure · TON Core

Built a shared Rust core for TON wallet applications, with bindings for Swift, Kotlin, C++, and TypeScript/WebAssembly. It handles wallet creation and import, transfers, transaction history, and TON Connect.

A single shared implementation keeps all wallet backend logic and its edge cases in one place, ensuring consistent behavior across platforms.

Wallet Engine powers Telegram’s native wallet in the iOS, Android, and Desktop apps.
